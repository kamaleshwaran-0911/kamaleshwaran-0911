## 🚀 Featured Project

### 🧠 Expert Decision Replay Platform

A full-stack decision-management application designed to help teams
document decisions, evaluate alternatives, collaborate, manage approvals,
and generate reports.

**✨ Key Features**
- 🔐 Authentication and role-based access control
- 📝 Decision tracking and version history
- 📊 Alternative analysis and reporting
- ✅ Approval workflows
- 💬 Discussion and collaboration
- 📈 Dashboards and analytics
- 📄 Report exports
- 🛡️ Audit logging and access controls

**💻 Technologies**
- Frontend: React, Vite, JavaScript, CSS
- Backend: Python, FastAPI
- Database: PostgreSQL, SQLAlchemy
- Security: JWT authentication
